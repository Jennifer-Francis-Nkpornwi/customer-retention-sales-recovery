# Excel Analysis

## Overview

This folder contains the Excel workbook used for the Customer Retention & Sales Recovery Analysis.

The workbook contains the prepared customer data, quarterly order analysis, customer segmentation, calculations, and interactive dashboard developed for the period January–September 2026 (Q1–Q3).

## Analysis Objectives

- Consolidate customer order records across three quarters.
- Analyse quarterly ordering patterns.
- Classify customer accounts according to their ordering behaviour.
- Identify inactive customers and accounts experiencing significant declines.
- Quantify changes in order volume.
- Support prioritisation of customer follow-up and sales recovery efforts.

## Data Preparation

Excel and Power Query were used to:

- Clean and prepare order data.
- Append separate order extracts.
- Standardise customer account references.
- Consolidate parent and sub-account relationships.
- Merge order records with customer master data using an Inner Join.

## Analytical Methods

The analysis used:

- Excel formulas to classify customer accounts.
- PivotTables to summarise quarterly order counts.
- Percentage-change calculations to measure changes in order volume.
- Filters and the SUBTOTAL function to validate customer counts and order totals.

## Dashboard

The workbook includes an interactive dashboard presenting:

- Customer accounts by segment.
- Quarterly order volume.
- At-risk accounts by category.
- Key customer retention and order-volume metrics.

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- Excel formulas

## Workbook

**File:** `customer-retention-sales-recovery.xlsx`

The workbook contains the analysis and interactive dashboard.

## Scope and Confidentiality

The analysis covers 93 unique parent customer accounts within the defined customer portfolio. The findings should not be interpreted as verified company-wide totals.

StrideWear Footwear is a simulated company identity. Customer identifiers and the presentation have been anonymised to protect confidentiality.
